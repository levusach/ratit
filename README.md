# Rat.it

Мой лично написанный терминальный текстовый редактор на плюсах. Он в честь моей крыски, и в нем она есть как маленький терминальный спутник.

Rat.it не такой сложный как vim: по ощущениям ближе к nano, только современней и с собственным характером.

## Возможности

- Меню выбора файла при запуске без пути
- UTF-8 редактирование текста
- Подсветка синтаксиса для C++ и Python
- Выделение, копирование, вырезание и вставка
- Undo/redo
- Поиск и переход к строке
- Save as
- Горизонтальный скролл длинных строк
- Поддержка мыши с переключением по бинду
- Настройки через `~/.ratitrc`

## Сборка

```sh
make
```

Или напрямую:

```sh
g++ -std=c++17 -O2 -Wall -Wextra main.cpp -lncursesw -o ratit
```

## Установка

```sh
sudo make install
```

## Использование

```sh
ratit
ratit path/to/file.cpp
```

Внутри редактора нажми `F1`, чтобы открыть меню помощи с биндами.

## Настройки

Опциональный `~/.ratitrc`:

```ini
tab_width=4
show_rat=true
mouse=true
```
